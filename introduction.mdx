\# 5centsCDN API Reference

5centsCDN provides a comprehensive set of APIs that enable you to programmatically manage your CDN infrastructure, live streams, video encoding, cloud storage, DNS, and analytics — all from a single RESTful interface.

\| Property | Value |

\|----------|-------|

\| **Architecture** | RESTful API |

\| **Data Format** | JSON |

\| **Version** | v2 |

\| **Base URL** | `https://api.5centscdn.com/v2` |

\| **Protocol** | HTTPS only |

\---

\## Authentication

All requests require an API key passed via request header.

\`\`\`bash

X-API-KEY: YOUR\_API\_KEY

\`\`\`

**How to obtain your API key:**

1\. Log in to your 5centsCDN dashboard

2\. Navigate to **Settings → API Keys**

3\. Generate a new key or copy your existing key

\<Warning>

Never expose your API key in client-side or public code. Rotate your key immediately if you suspect it has been compromised.

\</Warning>

\---

\## Request Format

**Required headers:**

\| Header | Value | When Required |

\|--------|-------|---------------|

\| `X-API-KEY` | YOUR\_API\_KEY | All requests |

\| `Content-Type` | `application/json` | POST and PUT only |

**HTTP Methods:**

\| Method | Purpose | Has Body |

\|--------|---------|----------|

\| `GET` | Retrieve a resource or list | No |

\| `POST` | Create a new resource | Yes |

\| `PUT` | Update an existing resource | Yes |

\| `DELETE` | Remove a resource | No |

**Example request:**

\`\`\`bash

curl -X POST <a href="https://api.5centscdn.com/v2/zones" target="_blank" rel="noopener noreferrer">https\://api.5centscdn.com/v2/zones</a> \\

&#x20; -H "X-API-KEY: YOUR\_API\_KEY" \\

&#x20; -H "Content-Type: application/json" \\

&#x20; -d '\{"name": "my-zone", "type": "HTTP"}'

\`\`\`

\## HTTP Status Codes

\| Code | Status | Description |

\|------|--------|-------------|

\| `200` | OK | Request succeeded. |

\| `201` | Created | Resource successfully created. |

\| `400` | Bad Request | Invalid request body or parameters. |

\| `401` | Unauthorized | API key missing, invalid, or expired. |

\| `403` | Forbidden | Insufficient permissions for this action. |

\| `404` | Not Found | The requested resource does not exist. |

\| `429` | Too Many Requests | Rate limit exceeded. Wait before retrying. |

\| `500` | Internal Server Error | Unexpected server error. Contact support if it persists. |

\---

\## Rate Limiting

**Limit:** 120 requests per minute per API key.

Exceeding the limit returns HTTP `429 Too Many Requests`.

**Best practices:**

\- Implement exponential backoff in automated scripts

\- Cache `GET` responses where data does not change frequently

\- Batch operations where the API supports it

\## API Modules

\| Module | Description | Base Path |

\|--------|-------------|-----------|

\| **Zones** | Create and manage HTTP, VOD, and Push delivery zones. Configure origins, caching, and SSL. | `/zones` |

\| **Live Streams** | Manage push and pull live streams. Enable DVR, ABR, and ad insertion. | `/streams` |

\| **Edge Rules** | Define custom routing and caching behaviors using path-based match rules. | `/zones/{zoneId}/edgerules` |

\| **Video Encoding** | Submit encoding jobs, manage presets, and monitor job status. | `/encoding` |

\| **SimpleDNS** | Create and manage DNS zones and records for your domains. | `/dns` |

\| **Cloud Storage** | Upload, list, and delete files across your cloud storage buckets. | `/storage` |

\| **Analytics** | Retrieve bandwidth, request counts, and traffic reports by zone or date range. | `/analytics` |

\| **Video Player** | Configure and embed video players with built-in analytics. | `/player` |

\| **Accounts** | Manage account settings, sub-users, API keys, and billing. | `/account` |
