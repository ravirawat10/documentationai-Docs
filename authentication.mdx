# Authentication

The 5centsCDN API uses API key authentication. Every request must include your API key in the request header. No OAuth, no tokens, no sessions — just one header on every call.

## Overview

<Tabs>
  <Tab title="How it works">
    ```json
    GET https://api.5centscdn.com/v2/zones
    X-API-KEY: YOUR_API_KEY
    ```
  </Tab>

  <Tab title="Get your API key">
    <Steps>
      <Step title="Step 1: Log in to your dashboard" title-type="p">
        Go to <a href="http://app.5centscdn.com" target="_blank" rel="noopener noreferrer">app.5centscdn.com</a> and sign in to your account.
      </Step>

      <Step title="Step 2: Open API Keys" title-type="p">
        Navigate to Settings → API Keys from the left sidebar.
      </Step>

      <Step title="Step 3: Copy or generate your key" title-type="p">
        Copy your existing key or click Generate New Key. Store it safely — it will not be shown again.
      </Step>
    </Steps>
  </Tab>

  <Tab title="Security rules">
    <Callout kind="alert" collapsed="false">
      Keep your key private. Your API key grants full access to your account. Never expose it&#x20;

      in client-side code, public repositories, or browser requests.
    </Callout>

    - Include it on every request — there are no public endpoints

    - Never commit it to Git — use environment variables instead

    - Rotate immediately if you suspect it has been compromised

    - One key = full account access — generate separate keys per environment
  </Tab>
</Tabs>

## Making an authenticated request

<Tabs>
  <Tab title="cURL">
    ```typescript
    curl -X GET https://api.5centscdn.com/v2/zones \
      -H "X-API-KEY: YOUR_API_KEY"
    ```
  </Tab>

  <Tab title="JavaScript">
    ```typescript
    const response = await fetch('https://api.5centscdn.com/v2/zones', {
      method: 'GET',
      headers: {
        'X-API-KEY': process.env.CDN_API_KEY
      }
    });
    const data = await response.json();
    ```
  </Tab>

  <Tab title="Python">
    ```typescript
    import requests

    response = requests.get(
        "https://api.5centscdn.com/v2/zones",
        headers={"X-API-KEY": "YOUR_API_KEY"}
    )
    data = response.json()
    ```
  </Tab>

  <Tab title="PHP">
    ```typescript
    $ch = curl_init();
    curl_setopt_array($ch, [
        CURLOPT_URL            => 'https://api.5centscdn.com/v2/zones',
        CURLOPT_RETURNTRANSFER => true,
        CURLOPT_HTTPHEADER     => ['X-API-KEY: YOUR_API_KEY']
    ]);
    $data = json_decode(curl_exec($ch), true);
    curl_close($ch);
    ```
  </Tab>
</Tabs>



## Authentication errors

<Tabs>
  <Tab title="Missing key">
    ```typescript
    {
      "status": "error",
      "errors": [
        {
          "code": 401,
          "message": "API key is required. Include X-API-KEY in your request header."
        }
      ]
    }
    ```
  </Tab>

  <Tab title="Invalid key">
    ```typescript
    {
      "status": "error",
      "errors": [
        {
          "code": 401,
          "message": "Invalid API key. Check your key or generate a new one."
        }
      ]
    }
    ```
  </Tab>
</Tabs>

| Code | Meaning                     | Fix                                                  |
| ---- | --------------------------- | ---------------------------------------------------- |
| 401  | Missing or invalid API key  | Check header name is X-API-KEY and value is correct  |
| 403  | Valid key but no permission | Contact support — your account may have restrictions |



## Best practices&#x20;

<Callout kind="info" collapsed="false">
  Use environment variables
</Callout>

```typescript
Never hardcode your API key. Store it as an environment variable.

CDN_API_KEY=your_actual_key_here
```

- Separate keys per environment — dev, staging, and production

- Rotate regularly — regenerate after any team member leaves

- Monitor usage — check dashboard for unexpected API activity

- Least privilege — use sub-accounts to limit key scope if available
