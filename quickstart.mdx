## Step-by-step

<Steps>
  <Step title="Create an API key" title-type="p">
    [Log in to your dashboard](https://www.5centscdn.net/dashboard/login), open the **Settings** menu → **Integration** → **API** to reach your API Keys list, then click **Add New**.

    - **Name** (required)
    - **Description** (required)
    - **Permissions** (required, choose at least one) — `Create`, `Read`, `Update`, `Delete`
    - **IP Whitelist** (optional) — one IP or CIDR per line; leave blank to allow any IP

    **Create** stays disabled until Name, Description, and at least one Permission are set.
  </Step>

  <Step title="Copy your key — it's shown only once" title-type="p">
    Creating a key opens its detail page with a banner showing the **plaintext API key**.

    <Callout kind="warning" collapsed="false">
      This is the only time the plaintext key is displayed — 5centsCDN does not store it. If you lose it, delete the key and create a new one.
    </Callout>

    <Callout kind="note" collapsed="false">
      Never paste your API key into public code, browser consoles, or Git repositories.
    </Callout>
  </Step>

  <Step title="Manage your key" title-type="p">
    The key's detail page stays available afterward under **Settings → Integration → API**.

    - **SHA-256 Fingerprint** — once the plaintext is gone, this hash is shown in its place. It uniquely identifies the key without exposing it, so you can reference it safely in logs or support requests.
    - **Edit** — update Name, Description, Permissions, or IP Whitelist, then click **Save**.
    - **Delete** — type the key's name to confirm. This cannot be undone.

    Multiple keys can also be selected from the list and deleted together.
  </Step>

  <Step title="Verify your key works" title-type="p">
    Make a test call to the account endpoint. A `200` response means your key is valid.

    <Tabs>
      <Tab title="cURL">
        ```bash
        curl -X GET https://api.5centscdn.com/v2/account \
          -H "X-API-KEY: YOUR_API_KEY"
        ```
      </Tab>

      <Tab title="JavaScript">
        ```javascript
        const res = await fetch('https://api.5centscdn.com/v2/account', {
          headers: { 'X-API-KEY': 'YOUR_API_KEY' }
        });
        const data = await res.json();
        console.log(data);
        ```
      </Tab>

      <Tab title="Python">
        ```python
        import requests

        r = requests.get(
          'https://api.5centscdn.com/v2/account',
          headers={'X-API-KEY': 'YOUR_API_KEY'}
        )
        print(r.json())
        ```
      </Tab>
    </Tabs>
  </Step>

  <Step title="List your zones" title-type="p">
    Fetch all CDN zones on your account.

    <Tabs>
      <Tab title="cURL">
        ```bash
        curl -X GET https://api.5centscdn.com/v2/zones \
          -H "X-API-KEY: YOUR_API_KEY"
        ```
      </Tab>

      <Tab title="JavaScript">
        ```javascript
        const res = await fetch('https://api.5centscdn.com/v2/zones', {
          headers: { 'X-API-KEY': 'YOUR_API_KEY' }
        });
        const data = await res.json();
        console.log(data);
        ```
      </Tab>

      <Tab title="Python">
        ```python
        import requests

        r = requests.get(
          'https://api.5centscdn.com/v2/zones',
          headers={'X-API-KEY': 'YOUR_API_KEY'}
        )
        print(r.json())
        ```
      </Tab>
    </Tabs>

    **Expected response:**

    ```json
    {
      "status": "success",
      "data": [
        {
          "id": 12345,
          "name": "my-zone",
          "type": "HTTP",
          "status": "active"
        }
      ]
    }
    ```
  </Step>

  <Step title="Explore the API reference" title-type="p">
    You are ready. Browse the full reference in the sidebar — every endpoint includes request/response schemas and a live playground to test calls directly.
  </Step>
</Steps>
